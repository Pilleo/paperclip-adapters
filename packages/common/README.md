# @pilleo/paperclip-adapter-common

Core shared library providing deterministic planning, multi-language blast radius discovery, Codanna symbol research, token-efficient code investigation, and skills materialization for Paperclip adapters.

## Key Modules
- `planning-engine.ts`: Multi-tier implementation planner (Tier 0: Pure deterministic synthesis, Tier 1: Codanna semantic AST outline & caller blast radius extraction).
- `code-investigation.ts`: Zero-dependency, language-agnostic structural outline parser and robust failure context window extractor for CI failure triage.
- `linter.ts`: Schema validator matching strict Backlog linter rules.
- `skills-materializer.ts`: Discovers and mounts workspace instructions, `AGENTS.md`, and skills into adapter execution bundles.
- `frontmatter.ts`: Fast zero-dependency YAML frontmatter parser and updater.
- `sanitizer.ts`: Environment and log sanitizer preventing leak of sensitive tokens and off-heap memory dumps.
